## Introduction  

Flutter is a modern UI toolkit from Google that allows you to build **beautiful, natively compiled applications** for mobile, web, and desktop from a single codebase. It's fast, expressive, and designed to make building user interfaces easy and fun.

---

## Prerequisites

Before you start, make sure you have the following installed:

- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/) or any code editor
- Basic knowledge of programming (preferably Dart or any OOP language)

---

## Steps to Get Started

Follow these steps to set up Flutter on your machine:

1. **Install Flutter**  
   Download Flutter from the [official website](https://flutter.dev/docs/get-started/install) and follow the installation guide for your operating system.

   ```bash
   # Verify Flutter installation
   flutter --version
    ```

2. **Set up your environment**

   * Add Flutter to your system PATH
   * Run `flutter doctor` to check for any missing dependencies

   ```bash
   flutter doctor
   ```

3. **Run your first app**

   * Create a new Flutter project:

   ```bash
   flutter create my_first_app
   cd my_first_app
   flutter run
   ```

   * This will launch your first Flutter app on an emulator or connected device.
